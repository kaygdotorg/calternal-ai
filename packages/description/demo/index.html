Description renderer demo

One Svelte renderer draws plugin descriptions (data, not code) against the disposable step 0 host. Everything here is development data: edits are lost when the host restarts.

  • Reading list
    Add a link (the form), see it appear, search from the footer. Real: the plugin operation through resolve and dispatch, the new row, the search flow. Stand-in: nothing is stored beyond the fixture's memory.
  • Notes (5,000 notes, three changes a second)
    Second line (age, snippet), the miniature in place of a thumbnail, row actions and menu, collections, Trash selector. Real: windows, counts, live churn. Stand-in: the editor is an empty box (the page's own editor draws it in the product), thumbnails are the host's snippet miniature, and only the actions this fixture host implements work; others answer with the host's own message.
  • Threads (5,000 threads, three changes a second)
    Inbox and All Threads, nested children, your sections, provider icons. Real: windows with parent refs, sections. Stand-in: the transcript and composer are empty boxes here (see the components page when it exists).

How to read the pages: arrows move the selection; Page Up/Down, Home and End only scroll. A long list asks the host for windows as you scroll, at most four requests a second.
