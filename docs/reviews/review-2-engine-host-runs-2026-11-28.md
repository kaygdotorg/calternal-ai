## Simplification opportunities

- Derive the reply operation and authority once from the installed binding and carry the resolved value in the run grant.
- Let receipt lookup return the write disposition directly. Once durable preparation is the only recovery source, remove seal-only receipt promotion.
- Carry typed frame boundaries through logs so the browser can checkpoint complete events. Read linked prompts with a bounded single-record lookup.
