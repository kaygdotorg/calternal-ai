# Notes

`calternal-notes` declares the stable `notes` kind and its `Notes/`
placement. The native engine projects Markdown into the index and uses the
host content service for revisions, Trash moves, and journal publication.

The native operation declarations in the shared Rust contract supply
discovery, authority, schemas, and risk metadata. See
[Notes operations](../../docs/notes-operations.md) for the request and
response fields, link behavior, and operator retention setting.
